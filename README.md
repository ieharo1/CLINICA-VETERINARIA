# ConexionAccess

Proyecto C# para conectar y gestionar bases de datos Microsoft Access.

## Descripción

Aplicación C# que permite conectar, consultar y manipular bases de datos Microsoft Access.

## Características

- Conexión a bases de datos Access
- Operaciones CRUD en Access
- Manejo de consultas SQL

## Stack Tecnológico

- C# .NET Framework
- ADO.NET
- Microsoft Access
